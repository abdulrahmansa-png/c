# بنك أسئلة الرخصة المهنية – كيمياء

موقع مذاكرة شخصي لاختبار الرخصة المهنية (كيمياء): 1276 سؤالاً مرتبة حسب الأهمية مع الشرح، ودرس لكل معيار من المعايير الـ17، واختبار محاكٍ بأوزان الهيئة، وصندوق أخطاء، ومؤشر جاهزية.

## التشغيل
- `index.html` الموقع، و`data.json` الأسئلة والدروس، و`img/` صور الأسئلة.
- يُحفظ التقدم في المتصفح نفسه (localStorage)، فلا يتزامن بين الأجهزة.
- لا يعمل بفتح الملف مباشرة (file://)؛ يحتاج خادماً: GitHub Pages، أو محلياً `python3 -m http.server` ثم افتح http://localhost:8000

## ملاحظة
الأسئلة مجمّعة من تجميعات ومصادر لأصحابها، للاستخدام الشخصي في المذاكرة فقط. يُفضّل أن يبقى المستودع خاصاً (Private).
